Technical Explanation

Clear, beginner-friendly details explaining how the algorithm operates and how to present this system to judges.

1. What is K-Means Clustering?

K-Means is an unsupervised machine learning algorithm that groups data points into K distinct clusters based on similarity. It works by initializing K center points (centroids), assigning each customer to the nearest centroid using Euclidean distance, and iteratively recalculating the centroid positions until they stabilize.

2. How It Works in This Project

The pipeline takes customer Annual Income and Spending Score, applies standard scaling (StandardScaler) so both features carry equal mathematical weight, and fits a K-Means model with K=3. The backend calculates cluster centers, maps each customer to their respective segment, and generates an automated scatter plot visualization.
